# Fuel efficiency and idling

## Why idling matters
An idling engine still burns fuel (roughly a quarter to a third of its working rate) while doing no
work. It also adds engine hours, which brings services forward, and it produces soot that loads the
exhaust aftertreatment. The app treats a session as **excessive idle** when the engine idles for more
than 50% of the session.

## Reducing idle time
- Shut down if you expect to wait more than 5 minutes (for example, waiting for a truck, a survey
  or a meeting), provided the engine has already cooled down after heavy work.
- Use the automatic engine idle shutdown and auto-idle features if the machine has them.
- Plan truck spotting so the loader or excavator is not waiting between loads.
- In mining, reduce queue time at the shovel by following dispatcher instructions and haul-road speed
  plans.

## Fuel per load cycle
The app compares fuel used per load cycle with the normal rate for the machine type. A session using
more than 1.5 times the normal fuel per cycle is flagged as a **fuel anomaly**. Common causes:
1. Long idle periods with few load cycles.
2. Clogged air or fuel filters (see *fault-codes.md*).
3. Running at full throttle for light work. Use the economy or standard power mode.
4. Poor technique: overfilling or underfilling the bucket, long swing angles, spinning wheels.
5. A fuel leak or theft. Check for wet fuel lines and compare with the tank level.

## Efficient operating technique
- Position the truck so the swing angle is 45–90 degrees instead of 180.
- Dig with the stick close to vertical and fill the bucket in one smooth pass.
- Avoid wheel spin on loaders; it wastes fuel and destroys tires.
- Use the lowest engine speed setting that gets the work done.
